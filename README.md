# 字字动画 Pixmax API 插件

这是一个给字字动画使用Pixmax API 生成图片和视频的插件。安装后，只需要填写 API Key，就可以在字字动画中获取模型并生成图片或视频。

## 包含内容

- `image_plugins/pixmax_openapi`：图片生成插件
- `video_plugins/pixmax_openapi`：视频生成插件

## 安装

1. 下载本项目全部文件。

2. 找到字字动画的安装目录。以常见的安装位置为例：

   ```text
   C:\Users\你的用户名\Desktop\字字动画_9_0_9
   ```

3. 进入下面这个插件目录：

   ```text
   字字动画_9_0_9\_internal\plugins
   ```

4. 按下面的对应关系复制插件文件夹：

   | 本项目中的文件夹 | 复制到字字动画的目录 |
   | --- | --- |
   | `image_plugins/pixmax_openapi` | `_internal/plugins/` |
   | `video_plugins/pixmax_openapi` | `_internal/plugins/` |

5. 如果目标位置已经有同名的 `pixmax_openapi` 文件夹，请用本项目中的文件覆盖其中的同名文件。

6. 完全退出并重新启动字字动画；如果软件有单独的后端进程，也要一并重启。

复制后请保持下面的文件结构不变：

```text
pixmax_openapi/
├─ main.py
├─ api_client.py
├─ info.json
└─ ui/
   └─ index.html
```

## 第一次使用

1. 打开 Pixmax 图片插件或视频插件。
2. 在 `API Key` 输入框中填写你的 Pixmax API Key。
3. 点击“连接并获取模型”。
4. 等待模型列表加载完成。
5. 选择需要使用的模型和参数，然后在字字动画中执行生成。

默认接口地址为：

```text
https://app.pixmax.cn/openapi
```

插件设置中提供了“API 地址”输入框。默认使用上面的地址；如果你使用兼容 Pixmax OpenAPI 的其他地址，可以在这里修改，保存后重新点击“连接并获取模型”。

## 图片生成

图片插件支持以下设置，具体选项会根据所选模型自动更新：

- 图片模型
- 分辨率
- 宽高比
- 质量
- 生成数量

如果某个模型不支持某项设置，该设置会自动禁用，生成时不会提交多余参数。

## 视频生成

视频插件支持以下使用方式：

- 没有参考图：文生视频
- 有一张参考图：图生视频
- 有多张参考图：根据模型限制自动选择兼容的模型

可配置的常见参数包括：

- 视频模型
- 分辨率
- 宽高比
- 时长
- 音频开关
- 码率模式
- 生成数量

不同模型支持的参数可能不同，插件会自动隐藏或禁用不适用的选项。

生成任务会显示进度状态：排队阶段显示“排队中”，执行阶段显示“生成中”和百分比，完成后显示 100%。

## 参考图和资产审核

参考图需要使用本地文件。视频生成时：

- 插件会自动上传参考图并取得资产 ID。
- Seedance/PIXDANCE 系列模型在使用参考图时会进行资产审核。
- 同一资产审核通过后，30 天内会复用审核结果，不会重复审核。
- 审核过期后，插件会自动重新审核。
- 如果使用多张参考图，而当前模型不支持，插件会自动切换到支持多图的模型。

## 生成结果

- 图片结果保存为 `.png` 文件。
- 视频结果保存为 `.mp4` 文件。
- 图片旁边可能会出现 `.pixmax.json` 文件，用于下次视频生成时复用资产信息。
- `.pixmax.json` 不保存 API Key。

## 常见问题

### 模型列表一直为空

请检查以下内容：

- API Key 是否填写正确。
- API Key 是否具有对应模型的使用权限。
- 网络是否可以访问接口地址。
- 是否点击了“连接并获取模型”。

### 提示参数非法或缺少参数

重新点击“连接并获取模型”，再重新选择模型。模型配置更新后，需要重新读取模型列表。

### 视频结果不是视频

请检查参考图和模型是否匹配。插件会自动排除输入的参考图片；如果接口返回的内容仍然不是视频，插件会提示错误，不会把图片保存成 `.mp4` 文件。

### 结果下载失败

请检查网络连接、API Key 权限以及生成结果地址是否可以访问。生成任务完成后，插件还需要下载最终素材才能保存到字字动画。
